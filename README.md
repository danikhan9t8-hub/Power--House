
# ⚡ Power House - Solar & Electrical Store

A modern and responsive e-commerce website for solar panels, electrical products, lighting, and hardware items.

## 🌐 Live Demo

[Visit Power House Website](https://danikhan9t8-hub.github.io/Power--House/)

## ✨ Features

- Modern and clean user interface
- Responsive design for mobile and desktop
- Solar and electrical product categories
- Product cards with images and prices
- Shopping cart functionality
- Quantity controls
- User-friendly navigation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Responsive Web Design

## 📦 Product Categories

- Solar Panels
- Solar Inverters
- Batteries
- Electrical Products
- Lighting
- Hardware
